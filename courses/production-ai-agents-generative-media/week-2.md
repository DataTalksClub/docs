## Nebius credits

1. Apply to the [Nebius AI Builder Program](https://dev.nebius.com/builders) separately from the course. The program sends AI Cloud and Token Factory codes in separate emails. Use the AI Cloud code for Serverless Jobs and Endpoints.
2. Follow the instructions in your code email. No credit card is required when you use the course promo code. You need a Nebius AI Cloud account with a tenant, which is created when you set up the account.
3. If a code is still missing two days after your Builder Program welcome email, or your application was rejected, send Mikhail a Slack DM with the email you used to apply. Use the [promo code guide](https://datatalks-club.slack.com/archives/C0CEG1BUDKL/p1794992006015909) and the [latest credit update](https://datatalks-club.slack.com/archives/C0CEG1BUDKL/p1795428925030219).

## GPU availability and spot pricing

If the Sana template offers no L40S, check the Capacity dashboard and try the eu-north1 region. Spot prices can change while a Job is running. Nebius bills each interval at the applicable spot price. Follow the [L40S discussion](https://datatalks-club.slack.com/archives/C0CEG1BUDKL/p1795019710267619) and the [spot pricing discussion](https://datatalks-club.slack.com/archives/C0CEG1BUDKL/p1795366558106759).
