## Tools and data sources used in the course

- [Google Colab](https://colab.research.google.com/) - where most of the course code runs.
- [yfinance](https://pypi.org/project/yfinance/) - free price data across many exchanges.
- [Alpha Vantage](https://www.alphavantage.co/) and [polygon.io](https://polygon.io/) - fundamental data and news, with free tiers.
- [TA-Lib](https://ta-lib.org/) - technical indicators.
- pandas, numpy, matplotlib, seaborn, and [Plotly Express](https://plotly.com/python/plotly-express/).
- [Streamlit](https://streamlit.io/) and GitHub Actions - dashboards and scheduled workflows.
