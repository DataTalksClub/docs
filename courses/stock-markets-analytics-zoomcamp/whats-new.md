# Changes

Notable points about the current state of the course.

## Cohorts

Two cohorts have run so far:

- 2024: the first cohort, started 15 April 2024.
- 2025: the second cohort, started 19 May 2025.

Between cohorts the course is available for self-paced study, and all materials stay in the GitHub repository. Materials from previous cohorts are preserved under the `cohorts` folder, including recordings, slides, homework, and past projects.

## Changes in the 2025 cohort

The core content stayed the same as in 2024.

These were the differences:

- A streamlined path. Research-style, open-ended homework questions were reduced so the course is doable with less time.
- New features in the data, such as tariffs and the performance of European or Chinese markets, to reflect the current economic environment.
- Less cloud and Docker in the automation module, in favor of GitHub Actions, a database, and Streamlit.
- More AI-assisted coding in the lectures.
- Two recorded prep workshops released before the cohort. See [Resources]({{ '/courses/stock-markets-analytics-zoomcamp/resources/' | relative_url }}).

Trading strategies also shifted with the market: after the 2025 market decline, market-neutral strategies with both long and short positions got more attention than single-stock long strategies.

## Where to check for the latest

Follow the module READMEs in the [GitHub repository](https://github.com/DataTalksClub/stock-markets-analytics-zoomcamp), plus the announcements in Slack and Telegram. Cohort dates appear on the [PythonInvest course page](https://pythoninvest.com/course).
