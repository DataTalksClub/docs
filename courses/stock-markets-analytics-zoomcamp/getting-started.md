# Getting Started

For the cross-course onboarding, read [Joining a Cohort]({{ '/courses/zoomcamp-logistics/joining/' | relative_url }}) first. It covers registration, account setup, calendar, and newsletter updates.

This page covers the Stock Market Analytics Zoomcamp specifics.

## Star the GitHub repository

[github.com/DataTalksClub/stock-markets-analytics-zoomcamp](https://github.com/DataTalksClub/stock-markets-analytics-zoomcamp)

All course materials are here. Each module has its own folder (for example `01-intro-and-data-sources`, `03-modeling`), and cohort-specific homework and deadlines are under the `cohorts` folder. Starring the repo helps other people find the course.

## Register

Registration happens on the [PythonInvest course page](https://pythoninvest.com/course). It is optional and free, and it is how you get cohort announcements by email.

## Join the Slack channel

After joining the [DataTalks.Club Slack workspace](https://datatalks.club/slack), find the `#course-stocks-analytics-zoomcamp` channel. This is where questions, announcements, and discussion happen. Before asking, read [Asking Questions]({{ '/courses/zoomcamp-logistics/asking-questions/' | relative_url }}).

## Follow the announcements

So you don't miss anything:

- Join the [course Telegram channel](https://t.me/stockanalyticszoomcamp).
- Subscribe to the [PythonInvest YouTube channel](https://www.youtube.com/@pythoninvest), where the lectures for this course are published, and turn on notifications so you do not miss a stream.

## How to work through the course

Use this order:

1. Watch the launch and Q&A session for the cohort to see how the course is organized.
2. Read the README in each module folder for an overview and video links.
3. Watch the lectures and do the homework. Aim for at least one or two questions from every homework even when you are short on time.
4. Start thinking about the project early. Many participants build it as they go through the modules rather than waiting for the submission window.
5. Submit the project, then review three peers' projects.

See [Environment Setup]({{ '/courses/stock-markets-analytics-zoomcamp/environment-setup/' | relative_url }}) for the tools and data sources you will use.

## Starting before a cohort

Materials change little between cohorts, so working through the previous cohort's modules is a good way to prepare. It also tells you whether your Python and pandas are strong enough, with time to catch up before the start.
