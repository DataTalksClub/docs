# AI Dev Tools Zoomcamp

AI Dev Tools Zoomcamp is a free, hands-on course on AI-native software engineering. You use AI developer tools to build, test, and deploy software. You also extend and audit it without losing engineering discipline.

The 2026 cohort starts on August 31, 2026. [Register for the free cohort](https://courses.datatalks.club/register/ai-dev-tools/) and use the [2026 course platform](https://courses.datatalks.club/ai-dev-tools-2026/) for the schedule, deadlines, homework submissions, and scores.

## Course outcomes

Across five modules, you take an application from an idea to a deployed system:

- Direct coding agents with specifications, project context, and independent verification.
- Build a tested full-stack application from an OpenAPI specification.
- Add integration tests, containers, CI/CD, and a public deployment.
- Add observability, bounded incident response, and security audits.
- Extend coding agents with MCP, skills, hooks, plugins, and specialized agents.

See the [curriculum]({{ '/courses/ai-dev-tools-zoomcamp/curriculum/' | relative_url }}) for module links. The materials also remain available for self-paced study, but graded submissions, peer review, and certificates are available only during a live cohort.
