# Getting Started

For the shared onboarding steps, read [Joining a Cohort]({{ '/courses/zoomcamp-logistics/joining/' | relative_url }}) first. It explains registration, account setup, calendar, and newsletter updates. Then use this page to join the AI Dev Tools Zoomcamp resources.

## Star the GitHub repository

[github.com/DataTalksClub/ai-dev-tools-zoomcamp](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp)

We keep all course materials in the repository. Open module folders such as `01-ai-native-workflow` or `03-deployment`, and find cohort-specific homework under `cohorts/2026`.

Create an account on the [2026 course platform](https://courses.datatalks.club/ai-dev-tools-2026/) to see the schedule, submit homework and the final project, and track your score. Registration for email updates and the course-platform account are separate.

## Join the Slack channel

After joining the [DataTalks.Club Slack workspace](https://datatalks.club/slack), find the `#course-ai-dev-tools-zoomcamp` channel for questions and discussion. Before asking, read [Asking Questions]({{ '/courses/zoomcamp-logistics/asking-questions/' | relative_url }}).

## Follow the announcements

Use Telegram for course announcements and YouTube for recordings:

- Join the [course Telegram channel](https://t.me/aidevtoolszoomcamp).
- Subscribe to the [DataTalks.Club YouTube channel](https://www.youtube.com/@DataTalksClub) and check the [course playlist](https://www.youtube.com/playlist?list=PL3MmuxUbc_hLuyafXPyhTdbF4s_uNhc43).

## Course workflow

Work through each module in this order:

1. Start with the [2026 course launch](https://www.youtube.com/watch?v=58pn873XO04) and Module 1, AI-Native Developer Workflow.
2. Read the README in each module folder for an overview and video links.
3. Watch the lectures (all pre-recorded) and do the homework.
4. Finish with the final project, then complete the peer reviews assigned on the course platform.

See [Environment Setup]({{ '/courses/ai-dev-tools-zoomcamp/environment-setup/' | relative_url }}) for the tools you'll use.
